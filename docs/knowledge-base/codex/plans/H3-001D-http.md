## 验证与非目标

G0–G6依适用规则执行；故意错误必须由断言证明失败。Node fetch实测不等于浏览器跨源/CORS验证；G7和教学应用交互均NOT_RUN：用户批准移至集中验收阶段。无浏览器调用、截图、安装或重试；不改知识库表现层，不新增框架/依赖，不部署教学HTTP服务。

不做DNS/TLS握手实验、超时性能结论、重试或真实API写入。网络失败通过本机测试路由关闭socket产生，避免猜一个未占用端口。GET读取固定合成数据；POST只证明405，不实现业务创建。
