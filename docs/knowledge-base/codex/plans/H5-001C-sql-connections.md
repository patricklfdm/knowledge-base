## 决策与恢复

同步调用可明确让连接A的事务跨越连接B的操作，这是真实数据库锁/可见性实验，不是同时执行的线程或HTTP压测。初始全部连接打开后才开始交错，避免把DDL初始化锁误判为业务写锁。事务结束/关闭后删除自身临时目录；WAL/SHM/日志与库一同清理，不手工删除仍在使用的日志。

只验证明确的SQLite模式/版本和错误码，busy与busy_snapshot分别解释；不让宽泛catch伪造预期错误。不写无限重试工具，失败后重新读取数据再决定动作。UI与生产并发/磁盘故障继续NOT_RUN。
