# 项目总纲

## 产品定位

建设一套可持续更新的中文全栈工程教材。初学者知道先学什么，开发者能快速查找做法，进阶读者能理解设计代价、失败边界和验证方法。网站是学习载体，不是为了练习前端而重造一个知识管理平台。

目标用户首先是项目拥有者本人，但笔记应让具备相应先修知识的其他读者也能理解。用户已有 Wayvia/GSE 开发经验，知识库仍覆盖 L0 入门；实际学习允许通过自测跳过基础，不省略教材的基础覆盖。

## 不变原则

分类回答“在哪里”，路线回答“先后顺序”，项目/实验回答“如何应用与验证”。同一概念只有一份权威正文，不为多条路线复制。

中文正文，首次出现重要术语附英文。详细不等于长篇堆叠；解释必须落到情境、机制、正确例子、失败例子、边界和迁移练习。

Markdown 为内容源，Obsidian 为编辑器，Git 为版本管理，Quartz 5 为静态发布，已有 GitHub Pages 为线上入口。通过配置和小范围扩展满足阅读需求，不默认替换成 Next.js/数据库系统。

公开与私密内容在整个仓库层面分开。文章编辑/核验状态和用户掌握情况分开。项目事实与教学假设分开。规划项不伪装成已完成链接。

## 双轨成果

平台轨：稳定构建与发布、可导航和搜索、良好中英文排版与移动阅读、元数据展示、先修/相关知识和路线导航、质量检查、维护说明。

内容轨：语言/Web 基础、首个端到端小应用、工程化、生产运行、系统与存储、分布式、数据工程、搜索与 AI 应用。先做样板，再按依赖扩展，不一次生成数百篇。

## 第一版 v1.0 的边界

v1.0 是 H0–H4 完成：平台可维护，基础路线完整，教学小应用可运行、有自动测试，阅读和发布门禁真实有效。不是“所有全栈知识已经写完”。知识库版本与 Quartz package.version 各自独立，不为发布 v1.0 把上游 package.version 改成知识库版本。

后续 v1.x/v2 内容拓展见 H5–H7；发布版本标签由用户另行授权，不自动创建。

## 非目标

本轮不做在线富文本编辑、实时协作、账号/收费系统、云同步学习进度、自动 AI 问答、独立向量数据库、云端大集群或真实生产服务运维。学习大数据不意味着知识库本身需要大数据基础设施。

首个教学项目不是 Wayvia 2.0，不依赖它的完整仓库或 LLM API。不擅自读取其他项目、复制内部资料、虚构项目指标或把旧设计称为现有实现。

## 可自主决定与需确认

可自主决定文章切分、文件 slug、样式细节、测试实现、轻量依赖和课程局部顺序，但必须保持目标并记录有影响的决定。新费用、框架迁移、重大 URL 破坏性调整、保密边界/许可证变化、外部项目访问、仓库权限变更必须确认。

不拿文章数、测试数或 Lighthouse 单个分数替代用户实际完成学习任务的能力。
