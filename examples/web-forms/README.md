# F07：页面与表单桥接

独立、无 npm 依赖的合成行程示例。Node.js 24.21.0；本地静态文件服务另用 Python 3.13.0。文件夹可复制到仓库外（包括含空格路径），不需要 Quartz、TypeScript 或父目录 node_modules。

## 终端验证

在此目录执行：

```sh
npm ci
npm test
npm run demo
npm run fail
```

前三条应成功；demo 打印 `山城 3 number` 与拒绝 `3e0` 的原因。最后一条故意传入31，必须非零退出，报“天数必须是1到30的整数”。测试专门断言这个失败，不把错误隐藏成成功。

## 页面文件与运行

- dom.html / dom.js：结构、选择元素、监听按钮、替换纯文本。
- index.html / form.js：收集 FormData、调用 fields.js、显示预览或错误。
- fields.js：纯输入转换/校验；接受首尾空白、前导零，拒绝非十进制整数文字，天数限1–30。
- style.css：仅此教学项目的基础排版。

在此目录执行（端口8080若被占用，换一个空闲端口）：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

服务只绑定本机，但会提供此目录的文件，请只在这个公开合成示例目录启动。读者可访问 `http://127.0.0.1:8080/dom.html` 和 `http://127.0.0.1:8080/`，Ctrl+C停止。不要双击HTML用file协议代替HTTP模块加载。此静态服务不接收保存请求；无需数据库、重置或凭证。

本轮按用户要求不启动浏览器。Node语法/业务测试和静态HTTP文本检查已经验证，详见仓库 reports/H3-web-forms.md；页面点击、Enter、焦点、屏幕阅读器与视觉为 **NOT_RUN：用户批准移至集中验收阶段**（H4-UI-APP）。预期交互：合法文字生成预览；错误显示原因并把焦点移到反馈；保留输入供修改。预期不等于实测。

## 边界与迁移练习

表单故意使用text+inputmode=numeric，明确接受的文字格式，不依赖number控件各浏览器输入处理。novalidate让本例的JS统一反馈；required保留必填语义。按钮在监听器装好后才启用，JS缺失时不提供可提交入口。客户端校验可绕过，未来服务器仍必须独立校验。没有网络API、数据库、本地存储、唯一ID或保存操作。

将上限30改14时，同时修改 fields.js、HTML提示、错误信息和测试；断言14通过、15拒绝。F06处理已经是number的对象；本例只在文字入口做转换。后续API层才整合共享业务规则，不为两篇桥接教材引入打包器。
